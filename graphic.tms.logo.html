Tracy Mini Spa: Logo Design

Goal: Create a logo for a local home-based lash tech.

Role: Graphic Designer

Technologies: Adobe Illustrator

Project Type: Academic Project

Completed: February 2025

Notes: Tracy Mini Spa’s primary presence is on Instagram, but it currently lacks a strong, cohesive brand identity. This project focuses on developing a logo that accurately represents and aligns with the brand.

The process began with a broad exploration of concepts through initial sketches, which were then refined to a select few. The strongest elements from the top two designs were ultimately combined to create the final logo. The logo draws inspiration from a closed eye, using the eyebrow to subtly form the crossbar of the “T.” The brand’s initials are rendered in a small-caps script, flowing downward into the eyelashes to visually represent the spa’s services. The lettermark is set in all caps for clarity and distinction, while “Mini Spa” is styled in a softer, small-caps script to maintain consistency with the initials and reinforce the brand’s delicate aesthetic.
